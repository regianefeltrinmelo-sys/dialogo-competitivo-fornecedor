# Como participar de uma contratação na modalidade Diálogo Competitivo

Manual técnico voltado para **fornecedores** com orientações passo a passo sobre como acessar uma contratação na modalidade **Diálogo Competitivo** e manifestar interesse em participar do certame no portal Compras.gov.br, em conformidade com a Lei nº 14.133/2021 e normativos aplicáveis.
